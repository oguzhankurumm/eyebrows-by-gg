# Eyebrows by GG design context

The current system is documented in `DESIGN.md` and `.impeccable/design.json`. Read `PRODUCT.md` and `.impeccable/surfaces/src-app-page-tsx.md` for product truth and the homepage contract.

- Five roles: lilac-white background, lavender surface, deep plum text, violet accent, muted plum supporting text. Exact values are CSS variables in `src/app/globals.css`.
- Sora display and Manrope body, self-hosted with swap. Two families only.
- Rounded controls, image-led treatment cards and generous section panels. Breakpoints serve 375/768/1440px.
- Original studio/Instagram photography and silent portfolio films; no synthetic treatment results.
- Finish selector, treatment filters, native before/after range, FAQ details and a stable inline treatment picker.
- Native appointment dialog opens GlossGenius in a secure separate window. Cross-origin framing is blocked by the booking provider.
- Four mobile navigation destinations and a distinct booking action; safe areas, keyboard focus and reduced motion are required.
- Historical source material remains internal. Never restore the rejected public Original website reference panel or the old shade-library design.

21st searches informed navigation and hero exploration. Component retrieval hit the free quota; shipping components were authored locally. No third-party paid component code is claimed.
